**Interfaces:**
- None — standalone cleanup.

**Design note (read before implementing):** The deferred-issue entry describes this `if` as dead code that "could be removed for clarity." That is **not quite right** — `setServerEnvironment`'s third parameter (`plugin.ts:99`) is typed `string`, not `string | false`, while the outer `serverEntry` (`plugin.ts:150`) is typed `string | false`. The `if (serverEntry !== false)` block is what lets TypeScript narrow `serverEntry` to `string` for the call — removing it outright breaks compilation (`string | false` is not assignable to `string`). The correct fix keeps type safety via an explicit, commented assertion instead of a runtime branch.

```typescript
						setServerEnvironment(options, appsettings, serverEntry)
					}
					break
```

to:

```typescript
				case environment.server:
					// Safe: configEnvironment is only invoked for environments present in
					// config.environments, and `server` is only registered there when
					// serverEntry !== false (see the `config` hook above).
					setServerEnvironment(options, appsettings, serverEntry as string)
					break
```
