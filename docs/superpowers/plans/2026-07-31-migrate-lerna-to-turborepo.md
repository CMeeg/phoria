# Lerna → Turborepo Migration Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the Lerna CLI and its bundled Nx engine with Turborepo as the monorepo task runner and cache, leaving pnpm (workspaces/installs) and Changesets (versioning/publishing) unchanged.

**Architecture:** Lerna 9 is a thin CLI over Nx (`nx >=21.5.3 < 23.0.0` hard dependency); `nx.json` already holds all task logic. Turborepo replaces both with one tool and a single `turbo.json` mirroring the seven existing `targetDefaults`. Root `package.json` gains convenience scripts (`build`, `lint`, `check`) and `test`/`test:browser` switch to `turbo run`; the `publish` flow drops the runner entirely (`pnpm --filter phoria-dotnet run publish` — only `phoria-dotnet` has a publish script). CI and docs follow.

**Tech Stack:** pnpm 11, Turborepo 2.x, Changesets, Biome, GitHub Actions.

## Global Constraints

- Spec: `docs/superpowers/specs/2026-07-31-migrate-lerna-to-turborepo-design.md`
- `turbo.json` must use the `tasks` key (Turborepo 2.x schema) — not the v1 `pipeline` key.
- Task semantics must match `nx.json`: `build`/`check`/`test`/`test:browser` depend on `^build` and are cacheable; `lint` is cacheable with no deps; `preview` depends on `build`, is `persistent: true`, and NOT cacheable.
- e2e apps (`framework-multiple`, `with-workspace`) are in the pnpm workspace graph and MUST stay included in `turbo run build` (parity with today).
- `publish` script: `changeset publish && pnpm --filter phoria-dotnet run publish`.
- Publishing flow (Changesets for JS, `scripts/dotnet/publish.js` for NuGet) is unchanged.
- No remote cache configuration (same as today — no Nx Cloud, no Vercel).
- Historical `docs/plans/*` files are NOT to be modified.
- `pnpm-lock.yaml` is regenerated via `pnpm install` — never hand-edited.
- JSON files use tabs (Biome). YAML (`pnpm-workspace.yaml`) is not Biome-formatted.
- Every task ends with a commit; keep commits scoped to that task's files.

### Task 1: Add Turborepo and create `turbo.json`

**Files:**
- Modify: `package.json` (root devDependencies — add `turbo`)
- Create: `turbo.json`
- Test: `package.json`, `pnpm-lock.yaml` (regenerated by install)

**Interfaces:**
- Consumes: nothing
- Produces: `turbo` binary available as `pnpm exec turbo`; `turbo.json` defining tasks `build`, `check`, `lint`, `preview`, `test`, `test:browser`

- [ ] **Step 1: Add the turbo devDependency**

Run: `pnpm add -D turbo`
Expected: installs latest 2.x; `turbo` appears under `devDependencies` in root `package.json`; `pnpm-lock.yaml` updated.

- [ ] **Step 2: Create `turbo.json`**

Create `turbo.json` at the repo root with:

```json
{
	"$schema": "https://turbo.build/schema.json",
	"tasks": {
		"build": {
			"dependsOn": ["^build"],
			"cache": true
		},
		"check": {
			"dependsOn": ["^build"],
			"cache": true
		},
		"lint": {
			"cache": true
		},
		"preview": {
			"dependsOn": ["build"],
			"persistent": true
		},
		"test": {
			"dependsOn": ["^build"],
			"cache": true
		},
		"test:browser": {
			"dependsOn": ["^build"],
			"cache": true
		}
	}
}
```

- [ ] **Step 3: Verify turbo can run tasks**

Run: `pnpm exec turbo run build`
Expected: succeeds; builds all packages (including e2e apps) in dependency order; `FULL TURBO`/cache line appears on a second run.

- [ ] **Step 4: Commit**

```bash
git add package.json pnpm-lock.yaml turbo.json
git commit -m "build: add Turborepo task runner"
```

### Task 3: Remove Lerna and Nx

**Files:**
- Delete: `lerna.json`, `nx.json`
- Modify: `package.json` (remove `lerna` devDependency), `pnpm-workspace.yaml` (remove `nx: true` from `allowBuilds`), `.gitignore` (add `.turbo/`)
- Test: `pnpm-lock.yaml` (regenerated)

**Interfaces:**
- Consumes: root scripts now call `turbo` only (Task 2)
- Produces: a toolchain with no `lerna`/`nx` packages in the lockfile; `.turbo/` gitignored

- [ ] **Step 1: Remove the lerna devDependency and delete config files**

Run: `pnpm remove lerna`
Then delete `lerna.json` and `nx.json`:
```bash
rm lerna.json nx.json
```
Then remove the untracked Nx cache directory:
```bash
rm -rf .nx
```
(`.nx/cache` and `.nx/workspace-data` are gitignored, so this is a local-only cleanup.)

- [ ] **Step 2: Update `pnpm-workspace.yaml`**

In `pnpm-workspace.yaml`, remove the `nx: true` line from `allowBuilds`:

```yaml
allowBuilds:
  '@biomejs/biome': true
  '@parcel/watcher': true
  esbuild: true
```

- [ ] **Step 3: Update `.gitignore`**

Add `.turbo/` after the `.nx` entries:

```gitignore
.nx/cache
.nx/workspace-data
.turbo/
```

- [ ] **Step 4: Regenerate the lockfile and verify**

Run: `pnpm install`
Then confirm no Lerna/Nx residue:
```bash
rg -n "lerna|nx@" pnpm-lock.yaml package.json pnpm-workspace.yaml || echo "clean"
```
Expected: no matches (tolerate `@nx` only if some other dependency pulled it — flag it if so).
Then verify the toolchain still works:
Run: `pnpm build && pnpm lint && pnpm check && pnpm test`
Expected: all green, running through turbo.

- [ ] **Step 5: Commit**

```bash
git add package.json pnpm-lock.yaml pnpm-workspace.yaml .gitignore lerna.json nx.json
git commit -m "build: remove Lerna and Nx in favour of Turborepo"
```
(`git add` on the deleted `lerna.json`/`nx.json` paths stages their removals; explicit paths keep this task's commit scoped.)
